# Dev Engineering

Мои собственные программные инструменты для инженерных задач. Здесь я собираю утилиты, которые написал сам для автоматизации расчетов, проектирования и рутины.

## 📂 Мои инструменты

- **[EngineerHelper](https://github.com/engicode-dev/engineer-helper)** — мой настоящий инженерный калькулятор (Python, Tkinter).
  Написан с нуля для быстрого расчета массы, геометрии, допусков и сварных швов. Включает интерфейс и ГОСТ-шрифты.
- **[TechRoute](https://github.com/engicode-dev/TechRoute)** — система автоматизации технолога (Python, Tkinter, OpenPyXL). Генерирует Маршрутные карты (МК), Операционные карты (ОК) и Спецификации по ГОСТ, считает режимы резания и массу заготовки.
- **[Freelance Ops](https://github.com/engicode-dev/freelance-ops)** — личный менеджер для фрилансера (Python, Tkinter, SQLite). Объединяет трекер задач, учёт доходов (активных и пассивных), таймер Pomodoro, личный дневник и графики. Собирается в единый исполняемый файл для Linux.

### 🛠️ Технологии

*   **Языки:** Python 3.10+
*   **GUI:** Tkinter, `ttkbootstrap` (современные темы для Tkinter)
*   **Базы данных:** SQLite (встроенная, не требует установки серверов)
*   **Данные и аналитика:** Matplotlib, NumPy
*   **Инструменты:** Git, Linux (MX Linux), PyInstaller (сборка в бинарники)
*   **Форматы данных:** JSON, CSV
