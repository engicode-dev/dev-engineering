# Dev Engineering

Мои собственные программные инструменты для инженерных задач. Здесь я собираю утилиты, которые написал сам для автоматизации расчетов, проектирования и рутины.

## 📂 Мои инструменты

- **[Engineercalc](./engineercalc)** — мой настольный инженерный калькулятор (Python, Tkinter). 
  Написан с нуля для быстрого расчета массы, геометрии, допусков и сварных швов. Включает интерфейс и ГОСТ-шрифты.

## 🛠️ Технологии
- Python (Tkinter, JSON)
- Git, Linux

## 🚀 Что в планах (Roadmap)
- Создание калькулятора зубчатых передач и балок.
- Написание скриптов для автоматизации FreeCAD.
- Разработка Telegram-ботов для инженерных расчетов.
